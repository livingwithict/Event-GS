## Step 1: Create the Subdomain in cPanel

1. Go to **cPanel > Subdomains** (or Domains)
2. Create subdomain: `events.ictfoundation.org.np`
3. Document root: `/home2/ictechco/events.ictfoundation.org.np/`
4. Note the exact home directory path (`/home2/ictechco/` or similar)

## Step 2: Create MySQL Database

1. Go to **cPanel > MySQL Databases**
2. Create database: `ictechco_event_management`
3. Create user: `ictechco_admin` (with a strong password)
4. Add user to database with **ALL PRIVILEGES**

## Step 3: Upload Files

Upload `event-management-production.zip` to `/home2/ictechco/` and extract.

```bash
cd /home2/ictechco
unzip event-management-production.zip
```

Verify the structure:
```bash
ls /home2/ictechco/event-app/artisan
ls /home2/ictechco/events.ictfoundation.org.np/index.php
ls /home2/ictechco/events.ictfoundation.org.np/.htaccess
ls /home2/ictechco/events.ictfoundation.org.np/scanner/index.html
ls /home2/ictechco/events.ictfoundation.org.np/build/manifest.json
```

## Step 4: Configure Environment

```bash
cd /home2/ictechco/event-app
cp .env.production .env
nano .env
```

Required values:

| Variable | Value | Notes |
|----------|-------|-------|
| `APP_KEY` | Leave empty | Auto-generated by deploy.sh |
| `APP_URL` | `https://events.ictfoundation.org.np` | No trailing slash |
| `DB_CONNECTION` | `mysql` | Already set |
| `DB_HOST` | `localhost` | Use `localhost`, not `127.0.0.1` |
| `DB_PORT` | `3306` | MySQL default |
| `DB_DATABASE` | `ictechco_event_management` | From Step 2 |
| `DB_USERNAME` | `ictechco_admin` | From Step 2 |
| `DB_PASSWORD` | Your password | From Step 2 |
| `MAILGUN_DOMAIN` | Your Mailgun domain | For email |
| `MAILGUN_SECRET` | Your Mailgun API key | For email |
| `SPARROW_SMS_TOKEN` | Your Sparrow token | For SMS |
| `SPARROW_SMS_FROM` | Your sender ID | For SMS |
| `CONNECTIPS_*` | Payment credentials | For payments |

## Step 5: Install Dependencies and Deploy

```bash
cd /home2/ictechco/event-app
composer install --no-dev --optimize-autoloader --ignore-platform-req=ext-intl
bash deploy.sh
```

If composer is not available globally:
```bash
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php composer.phar install --no-dev --optimize-autoloader --ignore-platform-req=ext-intl
```

First run of `deploy.sh` copies `.env.production` → `.env`. Edit credentials, then run again.

## Step 6: Set Up Cron Jobs

Go to **cPanel > Cron Jobs** and add **two** cron jobs:

**Application scheduler** (daily backups at 02:00, reminders at 09:00, thank-yous at 10:00):
```
* * * * * cd /home2/ictechco/event-app && php artisan schedule:run >> /dev/null 2>&1
```

**Queue worker** (processes emails, SMS, imports):
```
* * * * * cd /home2/ictechco/event-app && php artisan queue:work --stop-when-empty --tries=3 >> /dev/null 2>&1
```

## Step 7: Enable SSL

1. Go to **cPanel > SSL/TLS Status** or **AutoSSL**
2. Issue certificate for `events.ictfoundation.org.np`
3. HTTPS redirect is already in `.htaccess`

## Step 8: Set PHP Version and Extensions

1. Go to **cPanel > MultiPHP Manager**
2. Select `events.ictfoundation.org.np`
3. Set PHP to **8.4**
4. In **cPanel > Select PHP Version**, enable these extensions:
   `pdo_mysql`, `mysqli`, `mbstring`, `gd`, `bcmath`, `zip`, `openssl`, `tokenizer`, `xml`, `curl`, `intl`

## Step 9: Seed Admin User

```bash
cd /home2/ictechco/event-app
php artisan db:seed --class=RoleSeeder
```

Default admin: `admin@ictfoundation.org.np` / `password`

**Change the password immediately:**
```bash
cd /home2/ictechco/event-app
php artisan tinker
```
```php
$user = \App\Models\User::where('email', 'admin@ictfoundation.org.np')->first();
$user->update(['password' => bcrypt('YOUR-SECURE-PASSWORD')]);
exit
```

## Step 10: Disable Debug Mode

## Troubleshooting

### 500 Internal Server Error

Enable debug temporarily to see the error:
```bash
cd /home2/ictechco/event-app
sed -i 's/APP_DEBUG=false/APP_DEBUG=true/' .env
php artisan config:cache
```
Visit the page, read the error, then disable:
```bash
sed -i 's/APP_DEBUG=true/APP_DEBUG=false/' .env
php artisan config:cache
```

Check logs:
```bash
tail -50 /home2/ictechco/event-app/storage/logs/laravel-$(date +%Y-%m-%d).log
```

### 404 on /admin but / works

Clear and rebuild all caches:
```bash
cd /home2/ictechco/event-app
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan filament:clear-cached-components
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan filament:optimize
```

Check if admin routes are registered:
```bash
php artisan route:list --path=admin
```

If no admin routes appear, check Filament panel provider:
```bash
ls /home2/ictechco/event-app/app/Providers/Filament/AdminPanelProvider.php
```

### "could not find driver" (database)

The web PHP has different extensions than CLI PHP.

1. Go to **cPanel > Select PHP Version** for the domain
2. Enable `pdo_mysql` and `mysqli`
3. In **cPanel > MultiPHP Manager**, ensure same PHP version is selected
4. Verify with a `phpinfo.php` file:
```bash
echo '<?php phpinfo();' > /home2/ictechco/events.ictfoundation.org.np/phpinfo.php
# Visit https://events.ictfoundation.org.np/phpinfo.php
# Search for "pdo_mysql"
rm /home2/ictechco/events.ictfoundation.org.np/phpinfo.php
```

### "Access denied" (database credentials)

1. Go to **cPanel > MySQL Databases**
2. Verify database and user exist
3. Ensure user is **added to the database** (separate step from creating user)
4. Try changing `DB_HOST` from `127.0.0.1` to `localhost` (or vice versa)

### Scanner PWA blank

```bash
ls /home2/ictechco/events.ictfoundation.org.np/scanner/index.html
ls /home2/ictechco/events.ictfoundation.org.np/scanner/assets/
# Check browser console for 404s on asset files
```

### Storage symlink broken

```bash
rm -f /home2/ictechco/events.ictfoundation.org.np/storage
ln -s /home2/ictechco/event-app/storage/app/public /home2/ictechco/events.ictfoundation.org.np/storage
```

### Queue jobs not processing

```bash
cd /home2/ictechco/event-app
php artisan queue:work --stop-when-empty --tries=1 -v
php artisan queue:failed
php artisan queue:retry all
```

### intl extension missing

If composer warns about `ext-intl`:
```bash
composer install --no-dev --optimize-autoloader --ignore-platform-req=ext-intl
```

Then enable `intl` in **cPanel > Select PHP Version** when possible.
